## ADDED Requirements

### Requirement: 资源目录职责分离
系统 SHALL 将可跟踪种子数据、研究文档、本地基础库、项目状态、任务产物和导出结果存放在职责明确的独立目录中。

#### Scenario: 新环境初始化
- **WHEN** 用户在全新工作区初始化项目
- **THEN** 系统创建 `data/seed` 和 `var/library`、`var/projects`、`var/jobs`、`var/exports` 所需目录，并且业务代码不依赖旧运行产物存在

### Requirement: 运行资源不得进入版本控制
系统 MUST 将密钥、本地数据库、上传文件、解析缓存、日志、构建产物和预测运行产物排除在 Git 跟踪之外。

#### Scenario: 生成一次预测任务
- **WHEN** 系统生成日志、SQLite 数据库、任务 JSON 和图表图片
- **THEN** 这些文件位于忽略目录，`git status` 不显示新增运行资源

### Requirement: 历史资源安全迁移
系统 SHALL 提供非破坏性的迁移流程，将现有种子数据和工作台状态转换到新结构，并在校验成功前保留原文件。

#### Scenario: 迁移现有工作台数据
- **WHEN** 用户执行资源迁移命令
- **THEN** 系统复制或导入旧数据、输出迁移清单与校验结果，并且不删除原始文件

#### Scenario: 迁移中途失败
- **WHEN** 任一文件迁移或校验失败
- **THEN** 系统停止切换新路径、报告失败项，并保持旧流程仍可使用

### Requirement: 资源所有权可审计
系统 SHALL 生成资源清单，标明每个根目录的用途、是否进入 Git、清理策略和迁移状态。

#### Scenario: 查看资源清单
- **WHEN** 维护者检查项目资源说明
- **THEN** 可以区分源代码、种子数据、研究资料、第三方工具和可再生产物，并找到对应清理规则
