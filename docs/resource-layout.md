# 项目资源治理

## 目录职责

| 目录 | 用途 | Git 跟踪 | 清理策略 |
|---|---|---|---|
| `src/`、`config/`、`frontend/src/` | 业务源码与配置模板 | 是 | 人工维护 |
| `data/seed/` | 最小演示数据与旧固定主题兼容数据 | 是 | 版本化维护 |
| `docs/research/` | 方法说明和研究草稿 | 是 | 人工维护 |
| `var/library/` | 导入原文件、解析文本和 SQLite 索引 | 否 | 备份后清理 |
| `var/projects/` | 预测项目材料与项目快照 | 否 | 按项目归档 |
| `var/jobs/` | 预测中间产物和证据快照 | 否 | 按任务清理 |
| `var/exports/` | 报告与图片导出 | 否 | 可再生成 |
| `outputs/`、`logs/` | 旧 CLI 产物和日志 | 否 | 兼容期保留 |
| `.tools/`、`frontend/node_modules/`、`frontend/dist/` | 本地工具、依赖和构建产物 | 否 | 可再生成 |

## `skills/` 决策

业务源码和启动脚本未引用根目录 `skills/`。该目录属于外部 Agent 工具资源，并非预测系统运行时依赖。为避免破坏外部工作流，本变更保留该目录，不移动、不删除；后续由仓库所有者确认后再迁出。

## 迁移原则

1. `scripts/migrate_resources.py` 默认只输出计划。
2. `--apply` 仅复制文件，不删除源文件。
3. 每个目标文件使用 SHA-256 校验。
4. 任一校验失败时返回非零状态，旧路径继续可用。
5. 从 Git 索引移除历史产物是独立人工步骤，不由迁移脚本执行。

## 资源所有权

- 种子数据：预测方法维护者。
- 基础证据库和项目数据：本地操作者。
- 预测结果：项目创建者。
- Agent skills：外部工具维护者。
