# 面向 2040 智能建造 IPC 融合预测方法

## 研究边界

研究契约 v3 固定基线年为 2025，报告期为 2010—2014、2015—2019、2020—2025，预测节点为 2030、2035、2040。默认观测截止日为 2025-10-01，因此 2025 始终按部分年度标注并进入包含/排除敏感性分析。

规范网络输入是一项专利对应多个 IPC 的归属记录；同一专利中的规范化 IPC 无序对各贡献一次共现。只有经人工复核、包含支持数和分母定义的年度聚合边可作为降级证据。研究者提供的“融合概率”只保存为假设，不能写入模型概率字段。

## 目标与防泄漏

“首次出现”表示在截断时点尚无合格边、但在目标窗首次达到定义阈值；“显著增强”表示已有边在目标窗超过预注册的增幅与支持阈值。候选集合、负样本、最小支持、归一化层级和目标窗必须在运行清单中冻结。特征、IPC 映射、专利文本和论文信号的观测时间均不得晚于训练或预测截断点。

模型采用时间顺序选择和滚动起点验证，至少比较随机、流行率、共同邻居与 Adamic–Adar 基线。报告 Precision@K、Recall@K、Hit Rate@K、MAP/NDCG、可定义时的 PR-AUC、Brier 与校准误差；有效折或事件不足时显示“不可估计”，不得用零替代。只有支持充分的保留集校准结果才展示为概率，否则仅展示分数。

## Agent 边界与解释

LangGraph 节点依次冻结范围、运行确定性网络与模型、评审融合候选、综合专利/论文证据、接受科学批评、生成主题和情景路线图。LLM 只能生成解释和结构化主题，不能改写模型排名、概率、区间或来源记录。所有输出经过证据 ID、IPC、年份、结构和科学措辞校验，并在融合、主题和发布三个节点等待人工决定。

预测表示在给定数据、候选定义和情景假设下的条件判断，不是因果证明。部分 2025、映射缺失、证据冲突、校准不足、敏感性不稳定和专家覆盖必须紧邻相关结论展示。

## 图表与复现

交互图与静态图共享 `scientific-chart-v1`。观测用实线，预测用虚线，并用点形和文字重复编码。出版资产包含图号、图注、样本量、截止日、来源、契约版本、校验和和可访问说明；输出 SVG 与 600-DPI PNG。研究包的报告只读取冻结结构化产物，并包含逐文件校验清单。
